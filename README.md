# code1

Claude Code と Codex の両方から作業するための最小リポジトリです。

## 使い方

### Claude Code の場合

1. このリポジトリを GitHub に置く
2. Claude Code (claude.ai/code など) で GitHub を接続する
3. このリポジトリを指定してセッションを開始する
4. チャットで作業を依頼する

### Codex の場合

1. このリポジトリを GitHub に置く
2. Codex cloud で GitHub を接続する
3. このリポジトリ用の Environment を作る
4. スマホの ChatGPT から Codex に作業を依頼する

## 依頼例

```text
このリポジトリに小さなWebアプリを作って。変更後にREADMEも更新して。
```

## リポジトリ運用ルール

共通の運用ルールは `AGENTS.md` にまとめています（Claude Code は `CLAUDE.md` 経由でも同じ内容を参照します）。
